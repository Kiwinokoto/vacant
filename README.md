# VACANT — atlas documenté de Paris

Atlas public expérimental de la géométrie bâtie et des statistiques territoriales de vacance.

> **Statut : amorçage.** Aucun bâtiment ni logement individuel ne doit être présenté comme vacant sur la base d'un agrégat territorial. Les données historiques et les hauteurs manquantes ne sont jamais inventées.

Le socle de recherche et le démonstrateur en cours de préparation sont développés sur une branche dédiée avant revue. Aucun déploiement public n'est autorisé par défaut.
